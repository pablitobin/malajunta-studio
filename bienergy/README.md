# BiEnergy — Próximamente

Landing estática (HTML + CSS, sin build). Archivos: `index.html`, `logo.jpg`, `icon.png`.

## Deploy en Vercel
1. New Project → importar este repo.
2. **Root Directory:** `bienergy`
3. Framework Preset: **Other** (sin build command, sin output directory).
4. Deploy y luego agregar el dominio `bienergy.solar` en Settings → Domains.
